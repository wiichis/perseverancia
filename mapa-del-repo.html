Mapa de Open MCT para conectar a Percy

Open MCT es la “sala de control” de la NASA hecha página web: recibe los datos que envía una nave o un robot y los muestra en gráficas, tablas y paneles para que el equipo vea en todo momento cómo está.

Todas las referencias archivo:línea llevan al código en GitHub, en el commit analizado (al final de la página). Si no programas, puedes saltártelas: el texto de cada caja explica lo que pasa ahí.

Cómo está armado y cómo viaja un dato

A la izquierda, el núcleo: la base que arma la aplicación. A la derecha, el viaje de un dato (por ejemplo “velocidad de Percy = 0,04 m/s”) desde que llega hasta que se dibuja como un punto en una gráfica. El código de ejemplo que usa Open MCT es un “generador” que inventa una onda; para Percy lo reemplazaremos por datos reales del rover.

Las 5 piezas clave para conectar a Percy

De todo el repositorio, solo necesitamos entender estas cinco. La gráfica, las tablas y los paneles ya vienen hechos.

  1. El plugin: la caja donde va todo lo de Percy

    Una función que Open MCT ejecuta al enchufarla; dentro registramos las otras cuatro piezas.

    Como el enchufe de un aparato nuevo.

    src/MCT.js:435 · patrón a copiar: src/plugins/webPage/plugin.js:25–26

  2. El tipo de objeto “Percy”

    Le enseña a Open MCT qué es un “sensor de Percy” para que aparezca en el árbol de la izquierda y se pueda arrastrar a una gráfica.

    Como dar de alta un nuevo producto en un catálogo.

    TypeRegistry.js:59 · ejemplo: example/generator/plugin.js:64

  3. La ficha de cada medición (metadatos)

    Para cada dato de Percy: nombre, unidad, cuál es la hora (domain) y cuál el valor a graficar (range). Sin range, la gráfica no se ofrece.

    Como la etiqueta de cada columna de una hoja de cálculo.

    GeneratorMetadataProvider.js:10–15 · :45–51

  4. El proveedor de telemetría

    El “cartero” entre Percy y Open MCT: responde con el historial y avisa de cada dato nuevo en vivo. Se registra en la central de telemetría.

    Como un repartidor que trae los periódicos atrasados y además te llama cuando sale la noticia.

    GeneratorProvider.js:91 · :101 · registro: TelemetryAPI.js:167

  5. La hora de cada dato

    Open MCT pide los datos “desde tal hora hasta tal hora” según el reloj de la parte superior. Por eso cada dato de Percy debe llevar su hora (en milisegundos UTC).

    Como el sello de fecha en cada foto: sin él no se pueden ordenar.

    TelemetryAPI.js:237–256

Cómo conectamos Percy

“Percy” aquí es nuestro simulador 3D del rover (la carpeta perseverancia), que ya conoce su velocidad, rumbo, posición e inclinación. El plan: el simulador emite esos datos y un plugin de Open MCT los recibe. Nada de esto está construido todavía; son los pasos a seguir.

  1. Elegir qué mediciones mostrar

    Para empezar, cuatro: velocidad (m/s), rumbo (grados), posición X y posición Z (metros). Cada envío lleva además su hora.

    { "utc": 1760600000000, "velocidad": 0.04, "rumbo": 182, "x": -0.6, "z": -23.5 }

  2. Hacer que el simulador “hable”

    Cada medio segundo, el simulador envía ese paquete por un canal en vivo (un WebSocket) a un pequeño servidor puente que también guarda los últimos minutos, para poder dar historial.

    • El simulador y Open MCT corren en páginas distintas, por eso necesitan ese puente.
    • Si más adelante usamos datos publicados por la NASA, solo cambia este paso.

  3. Crear el plugin de Percy (pieza 1)

    Un archivo propio percy-plugin.js fuera del código de Open MCT, copiando la forma del ejemplo del generador.

    export default function PercyPlugin() {
  return function install(openmct) {
    // aquí van los pasos 4, 5 y 6
  };
}

  4. Dar de alta a Percy en el árbol (pieza 2)

    Registrar el tipo “Sensor de Percy” y una carpeta raíz “Percy” con las cuatro mediciones dentro, para verlas a la izquierda de la pantalla.

    • Herramientas: openmct.types.addType y openmct.objects.addRoot (explicadas en API.md:316 y API.md:349).

  5. Escribir la ficha de cada medición (piezas 3 y 5)

    Para cada una: la hora como utc con hints: { domain: 1 } y el valor (por ejemplo velocidad, unidad “m/s”) con hints: { range: 1 }. Es el mismo molde que la onda del ejemplo.

  6. Escribir el proveedor (pieza 4)

    • Historial: cuando Open MCT pida “desde-hasta”, preguntarle al puente y devolver la lista de paquetes.
    • En vivo: escuchar el WebSocket y avisar a Open MCT de cada paquete nuevo.
    • Registrarlo con openmct.telemetry.addProvider. Guía oficial: API.md:532.

  7. Enchufarlo y probar

    En la página que arranca Open MCT, añadir una línea junto a las de los ejemplos (como en index.html:104):

    openmct.install(PercyPlugin());

    Luego: abrir la carpeta “Percy”, hacer clic en “Velocidad” y conducir el rover con WASD. La línea debería moverse en tiempo real. Para una pantalla de misión, juntar las cuatro gráficas en un “Display Layout”.
