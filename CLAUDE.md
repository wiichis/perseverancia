# CLAUDE.md

Este proyecto es una simulación 3D del rover Perseverance de la NASA explorando la superficie de Marte. Claude debe ayudar a construir la escena (terreno marciano, iluminación y cielo), el modelo del rover con sus ruedas, brazo robótico y mástil de cámaras, y los controles para moverlo y explorar. Prioriza código simple, modular y bien comentado en español, usando tecnologías web 3D (por ejemplo, Three.js) salvo que se indique otra cosa.
